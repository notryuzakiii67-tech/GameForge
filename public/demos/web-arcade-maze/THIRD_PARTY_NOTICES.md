Adapted from **The Maze** in [Web Arcade by duysqubix](https://github.com/duysqubix/web-arcade), source revision `a8b8f278b9a11d0778b21ff0e5cfea27531bd4d8` (file `games/maze/index.html`). The source repository is MIT-licensed; the complete upstream notice is retained in [`LICENSE`](./LICENSE).

GameForge changes: moved maze generation and BFS into `maze-engine.js`; added reciprocal-wall/full-reachability validation with bounded retries and a visible retry state; removed the remote Soldier GLB model request and use the source's procedural monster instead; removed test-only debug hooks; made restart dispose scene-owned resources; and self-hosted the remaining runtime dependency. The original design, generated procedural textures/audio, and gameplay remain credited to Web Arcade.

## Three.js

The game bundles the Three.js `three.min.js` browser build from npm package `three@0.160.0` (npm package shasum `cd1e4dbd01aee0719280a9086d75545db52b7a8f`). It is self-hosted at `vendor/three.min.js`; no CDN request is made. The full MIT license and copyright notice are retained in [`vendor/THREE-LICENSE.txt`](./vendor/THREE-LICENSE.txt). No other runtime libraries or media assets are bundled; textures, audio, geometry, and creature art are generated by the game code.
