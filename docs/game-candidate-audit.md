# Game library and source-candidate audit

Audit snapshot: 2026-10-15. Each repository below was inspected at the exact commit listed in the table. A catalog record is not a claim of universal or production playability.

## Verification labels

- **Tested** — automated logic checks and headless Chromium browser play reached an observed terminal result (win, loss, or cleared round). The status records only the browser inputs and outcomes exercised; it is not a certification for physical devices, production services, every randomized seed, or every gameplay path.
- **Not fully tested** — a real game build is present and automated logic checks passed, but a complete browser playthrough to an outcome has not yet been recorded.
- **Blocked** — excluded from the playable catalog and has no Play action. The recorded legal, technical, or hosting requirement must be resolved before reconsideration.

## Test command map

- `npx vitest run tests/demo-games.test.ts` — shared maze logic, Neon Drift simulation, randomized Web Arcade maze checks, and Tower Defense simulation.
- `npx vitest run tests/third-party-games.test.ts` — 2048 game-manager behavior and session-only score handling.
- Headless Chromium browser checks used Playwright Core 1.64.1 and `@sparticuz/chromium` 153.0.0 installed only under `/tmp`; no browser dependency was added to the repository. Those checks exercised the actual GameForge player, game inputs, outcome screens, restart flows, and mobile touch emulation as summarized above. They do not certify physical devices, production hosting, or every random path.
