## Recovery configuration and migration notes

Email verification and password reset require all three server-only variables: `ACCOUNT_RECOVERY_SECRET` (at least 32 random bytes encoded as hex), `RESEND_API_KEY`, and `GAMEFORGE_EMAIL_FROM` (a Resend-verified sender). The names and setup notes are in `.env.example`, [SETUP.md](SETUP.md), and [VERCEL.md](VERCEL.md). None was tested against a real delivery provider in this worktree. No SMS provider is implemented or connected.

Migrations `0004_account_recovery_challenges`, `0005_private_asset_uploads`, `0006_versioned_project_asset_bindings`, `0007_asset_store_rights_and_review`, `0008_asset_store_imports_appeals_and_cleanup`, and `0009_retryable_asset_object_cleanup` are present in local SQLite. Migration 0008 adds import provenance and appeals; migration 0009 adds per-object cleanup retry state and backfills legacy cleanup candidates. Migration `0003_username_first_accounts_and_recovery_contacts` adds case-insensitive username/email unique indexes; production operators must inspect existing duplicate/case-variant values before applying it. Migrations 0003 through 0009 have **not** been applied to a production database.

## External providers and asset formats

- **AI:** no Gemini, Mistral, or Groq provider key was configured or tested. Provider-adapter behavior has local mocked coverage only; setting an env variable is not evidence of a successful connection.
- **Email:** Resend integration code exists, but no credentials or real delivery test.
- **SMS:** not implemented.
- **Private/public assets:** local uploads and owner-authenticated previews are implemented for PNG/JPEG/WebP, self-contained glTF 2.0/GLB 2.0 with embedded buffers and supported textures, PCM/IEEE-float WAV, and OGG Vorbis/Opus. Public downloads are limited to moderator-approved declarations under CC BY 4.0, CC BY-SA 4.0, or CC0 1.0 and are served as attachments. Ownership declarations are self-attested; the validator is structural, not independent rights verification, a full codec decoder, antivirus, or malware scanning. OBJ/FBX, SVG, external model references, unsupported compressed geometry, and animation-only formats are not supported.
- **S3 asset storage:** presigned POST policy conditions and exact-size constraints have mocked local tests only. No real S3 bucket, CORS, or production upload has been connected or tested.
- **Asset AI:** the Studio attaches only selected filenames and measured metadata to text prompts; raw asset bytes are not sent. No AI image/model generation or multimodal asset provider is configured or implemented.
- **Game repositories:** the integrated and blocked candidates, revisions, licenses, runtime requirements, and play evidence are detailed in [game candidate audit](game-candidate-audit.md). Freeciv-Web is not a standalone HTML build; HexGL contains non-commercial components; other candidates remain blocked pending sandbox/runtime review.
